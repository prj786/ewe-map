# ewe-map — the memory of the ewe OS project

This is the published version of the **ewe project-map vault**: the
Obsidian-style knowledge base that guides development of
[ewe](https://github.com/prj786/ewe) — an Arch-based, dark, Wayland
operating system.

## Start here

- [[Home]] — the map of everything
- [[00 Onboarding]] — read first if you're working on ewe
- [[Quick Answers]] — the 30+ most-likely questions, answered in one line

## The layers

- **01-Overview** — what ewe is, the repo inventory, roadmap, glossary
- **02-Architecture** — system layers, the shell, the one file, sync
- **08-Decisions** — every load-bearing decision and *why* (don't relitigate)
- **09-Rules** — the invariants; each says what breaks if violated
- **10-Roadmap** — what's next per component + open questions
- **11-How-We-Work** — dev loops, testing, releases, troubleshooting
- **12-Reference** — IPC verbs, ewe.conf schema, keymap, manifest, storage, versions

The machine-readable mirror of the contracts lives in
[`ewe-facts.json`](https://github.com/prj786/ewe-map/blob/main/ewe-facts.json).

Browsing tip: open the **graph view** (top-right) to see how the notes
connect.
