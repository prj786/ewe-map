# Roadmap — the desktop & the one file

Current: ewe DE **0.22.1-beta** (VERSION). The README speaks of the `0.9.x`
beta line; **1.0-beta is "Dolly"**.

## The one-file rollout (RFC-001)

| phase | content | status |
|---|---|---|
| 1–4 | theme, dock, layout, static artifacts | landed in 0.9.0 |
| 4 (special) | `hypridle.conf`, `monitors.lua` | **stay shell-generated by design** — runtime-reactive on battery/hotplug |
| 5 | `user.lua`, `input.lua` state models | follow when their models move into the file (0.9.7+: `desktop.input`, `desktop.layout` landed) |
| 6 | broker + sync | became RFC-005/RFC-006 — done as Nextcloud |

**Next work:**

- **"Dolly" 1.0-beta** — the named target: one-file complete, repo signed,
  beta polish.
- Continue moving remaining config surface into `ewe.conf` *only where the
  state model is stable* — never `hypridle.conf`/`monitors.lua` (rule, see
  [[Parked and Rejected Ideas]]).
- `ewe-conf` schema v1 is the contract — changes bump the schema and the
  docs together ([[EWE-CONF Schema Reference]]).

## Theming (ewe-design-v3, phases)

The v3 token system landed (2026-09-17/18):

- Phase 1: `ewe-theme` derives the full token set from a Base24 scheme +
  accent; builtins `ewe-dark` (default) and `ewe-light` (website toggle).
- Phases 2–3: Geist/Geist Mono fonts, `Theme.qml` one-property-per-token.
- Phase 6: Ewe names only — Fluent aliases and old `themes` block removed.

**Next work:**

- Text-size scaling: scales type AND control heights; the bar steps up an
  icon size at 130, the dock keeps its cells.
- A11y modes are remaps over the scheme — extend them, don't fork schemes.
- Watch the "never wrap a `control*` in `Theme.grow()`" rule (already
  grown).

## The shell

- In-shell Settings/AppStore panels remain **fallbacks only** — the Tauri
  binaries are the real UIs.
- Power menu in Quickshell is "on the list".
- Keep the two-singleton architecture (`Globals.qml`, `Theme.qml`) — new
  surfaces plug into it.

## Plugins

- `ewe-plugin create|dev|place|set|get` shipped with desktop-widgets
  (arrange mode `Super+Shift+W`). Next: richer settings types, Komble's
  Plugins form, third-party ecosystem growth.
- Bundled plugins refresh on version change; `seed --restore` undoes a
  removal.
