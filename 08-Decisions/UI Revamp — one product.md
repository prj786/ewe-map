# UI Revamp — one product

**Decided 2026-11-01 (owner): "revamp ui of control center and all apps. And also
plugins in komble. I want ui and ux polishment. Also plugin for ram usages should
have one more section for internet speed. Totally remove it from control center. I
want good ewe feeling sam naming style for apps. Now some are ewe-sync Some Ewe
Browser I want same writing style."** Process: before/after mockups first (Design
canvas "ewe UI revamp"), owner approved them ("Both are great, start a new release"),
then one release wave.

## The four answers

| question | owner's pick |
|---|---|
| names | **"ewe + Word"** — ewe Settings, ewe Sync, ewe Browser, ewe Safe, ewe Cast; Komble and Shaun keep their own names |
| System monitor | **bar readout + click card + the same card as a desktop widget**; no Quick settings tile |
| depth | **polish within design system v3** — ewellow, Geist, tokens, Glass stay; layout, hierarchy, spacing, empty states, wording, interactions change |
| process | **mockups first**, then build |

Two calls the owner confirmed on the mockups: notifications stay **inline** in Quick
settings (the clock and the bell share the Quick settings button — a decided bar
rule), and the System monitor readout is **in the bar by default** once installed.

## The naming rule (don't relitigate)

- Lower-case **ewe**, one space, capitalised Word: *ewe Settings*, *ewe Sync*, *ewe
  Browser*, *ewe Safe*, *ewe Cast*. **Komble** and **Shaun** are proper names.
- **Display names only.** Binaries, packages, desktop-file names, app ids /
  `StartupWMClass`, IPC targets, D-Bus and keyring service names, config keys, CLI
  names, repos and file names keep `ewe-settings`, `ewe-sync`, `ewe-safe`,
  `ewe-browser`, `ewe-cast`, `komble`. Renaming one of those breaks installed
  binaries (Rule 4).
- Launcher keywords still find *settings, sync, browser, passwords, cast*.
- A page path *inside* an app keeps the app's own word ("Settings → Keyring" in ewe
  Safe). Generated-file banners ("AUTO-GENERATED by Settings → …") stay: ewe-conf and
  ewe-settings' `hypr.js` must write them identically, so a change is one
  coordinated edit across both repos.
- The bar's focused-app label comes from the **desktop entry's Name** (it used to
  title-case the class up to the first dash, so every ewe app read "Ewe").
- Written into `design/system/guidelines/30-writing.md`.

## What changed, per surface

- **Quick settings** — no rail; see [[Desktop Shell]] (header, tiles with icon
  circles, shortcut row, inline notifications, battery + power-mode footer, pages in
  place, Esc goes back, height follows content, a Power page). The `quick-page`
  manifest and `quicksettings tab <key>` are unchanged; `remote` and `power` became
  reserved page keys.
- **System monitor 2.0.0** — [[System Monitor Plugin]]: CPU · memory · internet speed
  in the bar, a card, an optional desktop widget; host gained `desktopWidget.visible`.
- **Komble 0.21** — every plugin is one row (icon, name, one line, category; a switch
  when installed, Install when not, ⋯); a click opens the plugin's **sheet** (version,
  source, what it adds, Needs, its options, Show in the bar / Show on the desktop,
  widget pin/lock/position, Update / Remove) — the Options dialog is gone,
  `komble --options=<id>` opens the sheet. One primary **Add plugin…** (git URL + the
  unsandboxed warning in the sheet). Nav groups **Get apps** (Discover, For you, AUR)
  · **Your apps** (Installed, Updates) · **Desktop** (Plugins); Ctrl+1…6 follow that
  order. Updates and Installed show first-party packages by display name
  (`src/lib/names.js`).
- **ewe Settings 0.22** — nav in four groups: **Look** (Appearance, Wallpaper,
  Animations, Accessibility) · **Desktop** (Layout, Window rules, Displays, Startup
  apps, Keyboard shortcuts) · **Devices** (Network, Bluetooth, Keyboard and mouse,
  Power, Screensaver) · **System** (Default apps, Time and place, User, About this
  computer); **Find a setting** (Ctrl+F; page names, row titles, synonyms; opens,
  scrolls to and highlights the row). One page grammar on all 18 pages; the Glass
  switch reveals its opacity slider; no script or file names in the UI; the Switch
  has its ✓/✕ thumb. Restart shell moved to About this computer (asks first).
  Fixes: viewing Keyboard and mouse no longer writes `[desktop.input]`; `theme_scheme`
  pokes sync only for verbs that write.
- **ewe Sync, ewe Safe, ewe Browser** — see their component notes (this release).

> **Build guard:** a new app or a renamed surface takes an "ewe + Word" display name
> and keeps a dashed id. Never rename an id to match a display name. Never put the
> System monitor back into Quick settings.
