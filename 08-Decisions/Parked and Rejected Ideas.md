# Parked and Rejected Ideas

The graveyard. Everything here was considered and deliberately **not**
built — with the reason. A future session that re-proposes one of these
must read the reason first; it has usually not changed.

| idea | verdict | reason |
|---|---|---|
| Light mode | **accepted 2026-10-14** (was parked) | parked 2026-09-01 as dark-only; the scheme system brought Ewe Light back as a pickable desktop scheme, and the owner made light mode official on 2026-10-14 ("we need light mode too"). See [[Foundation Choices]] → *Dark by default, light mode too*. |
| Passkeys in Safe | **accepted 2026-10-15** (was parked in `ewe-safe/PLAN.md` §18) | parked because Linux has no passkey provider API for native apps; ewe browser now asks Safe itself, so none is needed. Stored in KeePassXC's format. See [[RFC-008 — ewe Safe]] → Amendment 2026-10-15 |
| SSH agent in Safe | **accepted 2026-10-15** (was parked in `ewe-safe/PLAN.md` §18) | parked because the SSH plugin and KeePassXC existed; the owner pushes with 1Password's agent and wants Safe to do it. KeeAgent's format. See [[RFC-008 — ewe Safe]] → Amendment 2026-10-15 |
| Google-first account & sync | **rejected → superseded** | RFC-002's Google half was replaced by RFC-005 (Nextcloud). Google survives only as BYO-client optional extra. |
| Wi-Fi-PSK sync (syncing Wi-Fi passwords in the bundle) | **dropped** | deliberately, per rule 4: secrets never enter the file/bundle. |
| In-app Nextcloud registration | **rejected** | needs admin credentials / provider signup forms; linking out is the honest maximum. |
| Owner-run Nextcloud to make registration work | **rejected** | puts the owner back in the loop as operator (cost, abuse, backups, liability) — the thing RFC-005 removes. |
| Writing our own folder-sync engine | **rejected** | multi-year project; `nextcloudcmd` *is* that project. UI + scheduler around it; fallback `rclone bisync`. |
| Per-package upgrades in Komble | **impossible** | Arch partial upgrades are unsupported. |
| Qt/KDE first-party apps or `plasma-integration` | **rejected** | traditional GTK + one `mimeapps.list`; Qt is a themed fallback only. |
| hyprpaper wallpapers | **dropped** (0.3) | replaced by per-type backends: mpvpaper (video) / swww (`awww`) / swaybg (static fallback). |
| Selective sync inside a folder pair | **not yet** | use excludes; the engine limitation is documented. |
| Bandwidth limits for folder sync | **not yet** | documented limit. |
| Chromecast true mirroring (real-time) | **future milestone** | Google's protocol; HLS today is seconds of latency, honestly stated. |
| Rust rewrite of ewe-castd | **parked** | deviation recorded (RFC-004); trigger is measured performance, not principle. |
| Native QtWebEngine OAuth webview | **later phase** | browser round-trip works; webview stays a later phase. |
| Submodules for bundled plugins | **rejected** | `git archive` ships vendored copies; a submodule would arrive empty. `scripts/vendor-plugins.sh` copies them in. |
| Sandboxing plugins | **impossible** | one QML engine; honesty instead (see [[Plugins Unsandboxed]]). |
| A second sync button anywhere | **rejected** | ewe-sync owns sync, full stop (RFC-006). |
| Moving runtime-reactive files into `ewe.conf` | **rejected** | `hypridle.conf`/`monitors.lua` stay shell-generated by design (battery/hotplug reactivity). |
| Translating ewe's own interface (shell, the six apps, installer, site) | **parked** (2026-11-21, owner: "no translation for now") | it touches every string in every repo; it deserves its own wave with a string-extraction step first. The 0.46 wave makes ewe *read, type and check* every language ([[Language Lives in Two Places — ewe.conf and the locale]]), not *speak* them. |
| fcitx5 (or ibus) shipped to everyone | **rejected** (2026-11-21) | RAM and ISO size for a feature most people never use; installed on demand from ewe Settings ([[Typing in Other Languages — fcitx5 on demand]]). |
| `GTK_IM_MODULE=fcitx` | **rejected** (2026-11-21) | not needed: GTK, kitty and Qt ≥ 6.7 type through the compositor's text-input protocol on Wayland (`bin/ewe-ime`, `docs/SETTINGS-BACKEND.md`); only X11, Qt 5 and SDL get variables. |
| LANG / LC_* in `ewe.conf` | **rejected** (2026-11-21) | the file syncs — one machine's locale would land on another; the locale is the machine's (`localectl`). |
| Flatpak (for Stremio Service or anything else) | **rejected** (2026-11-21) | ewe is pacman-only (rule 10); Komble places Stremio's own `server.js` where Stremio Enhanced looks ([[What an Installed App Still Needs]]). |
| ewe Player remuxing split video + audio with ffmpeg | **parked** (2026-11-21) | none of the tested sites (YouTube, Twitch, BBC) needed it — HLS master / progressive / DASH cover them; split-only sites offer *Open in mpv* ([[ewe Player Plays Links — yt-dlp]]). |
| Hunspell → `.bdic` conversion so ewe Browser checks Georgian | **parked** (2026-11-21) | needs Chromium's `convert_dict` or a renderer-side provider; ewe Browser says which languages it does not check ([[Spell Checking — hunspell and Chromium]]). |

## How to add an entry

When you reject an idea (or park it), add a row here **with the reason**,
and — if it cost real design time — an RFC or a CLAUDE.md "don't
relitigate" line. The graveyard is how this project avoids doing the same
analysis twice.
