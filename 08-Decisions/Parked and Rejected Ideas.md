# Parked and Rejected Ideas

The graveyard. Everything here was considered and deliberately **not**
built — with the reason. A future session that re-proposes one of these
must read the reason first; it has usually not changed.

| idea | verdict | reason |
|---|---|---|
| Light mode | **parked** | dark-only by decision (2026-09-01). A full *scheme* system exists instead — Ewe Light exists as tokens (website toggle), not as a desktop mode. |
| Google-first account & sync | **rejected → superseded** | RFC-002's Google half was replaced by RFC-005 (Nextcloud). Google survives only as BYO-client optional extra. |
| Wi-Fi-PSK sync (syncing Wi-Fi passwords in the bundle) | **dropped** | deliberately, per rule 4: secrets never enter the file/bundle. |
| In-app Nextcloud registration | **rejected** | needs admin credentials / provider signup forms; linking out is the honest maximum. |
| Owner-run Nextcloud to make registration work | **rejected** | puts the owner back in the loop as operator (cost, abuse, backups, liability) — the thing RFC-005 removes. |
| Writing our own folder-sync engine | **rejected** | multi-year project; `nextcloudcmd` *is* that project. UI + scheduler around it; fallback `rclone bisync`. |
| Per-package upgrades in Komble | **impossible** | Arch partial upgrades are unsupported. |
| Qt/KDE first-party apps or `plasma-integration` | **rejected** | traditional GTK + one `mimeapps.list`; Qt is a themed fallback only. |
| hyprpaper wallpapers | **dropped** (0.3) | replaced by per-type backends: mpvpaper (video) / swww (`awww`) / swaybg (static fallback). |
| Selective sync inside a folder pair | **not yet** | use excludes; the engine limitation is documented. |
| Bandwidth limits for folder sync | **not yet** | documented limit. |
| Chromecast true mirroring (real-time) | **future milestone** | Google's protocol; HLS today is seconds of latency, honestly stated. |
| Rust rewrite of ewe-castd | **parked** | deviation recorded (RFC-004); trigger is measured performance, not principle. |
| Native QtWebEngine OAuth webview | **later phase** | browser round-trip works; webview stays a later phase. |
| Submodules for bundled plugins | **rejected** | `git archive` ships vendored copies; a submodule would arrive empty. `scripts/vendor-plugins.sh` copies them in. |
| Sandboxing plugins | **impossible** | one QML engine; honesty instead (see [[Plugins Unsandboxed]]). |
| A second sync button anywhere | **rejected** | ewe-sync owns sync, full stop (RFC-006). |
| Moving runtime-reactive files into `ewe.conf` | **rejected** | `hypridle.conf`/`monitors.lua` stay shell-generated by design (battery/hotplug reactivity). |

## How to add an entry

When you reject an idea (or park it), add a row here **with the reason**,
and — if it cost real design time — an RFC or a CLAUDE.md "don't
relitigate" line. The graveyard is how this project avoids doing the same
analysis twice.
